# E-Commerce Platform
ASP.NET Core 7 + React 18 + Redux + Stripe Payments

A full-scale, real-world E-Commerce Web Application built using modern enterprise technologies and production-ready architecture.
This project demonstrates my skills in backend API development, frontend engineering, authentication, state management, database design, payment processing, and cloud deployment.

# Tech Stack

**🧠 Backend Engineering (ASP.NET Core 7)**

⦁	RESTful API development with .NET 7 Web API
⦁	SOLID principles & layered architecture
⦁	Data access with Entity Framework Core
⦁	Repository-style patterns using EF capabilities
⦁	Database migrations & schema design
⦁	ASP.NET Core Identity for authentication & authorization
⦁	Token-based security using JWT
⦁	DTO mapping with AutoMapper
⦁	Stripe 3D Secure Payment integration
⦁	Error handling middleware & validation pipeline

**⚛️ Frontend Engineering (React 18 + Redux)**

⦁	Modern React SPA using Create React App
⦁	Redux Toolkit for global state management
⦁	React Router v6 for route-based navigation
⦁	UI built with Material UI
⦁	Reusable form components using React Hook Form
⦁	Axios for API communication
⦁	Persistent shopping cart logic
⦁	PLP (Product Listing Page):
⦁	Paging
⦁	Sorting
⦁	Searching
⦁	Filtering
